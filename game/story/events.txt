# Scripted moments, per shift, at a facility time (HH:MM). They only happen
# while the supervisor is on duty, and only if the condition holds (empty =
# always; see Campaign.check: knowledge keys, !key, standing>=70, trust:x>=2 ... with &).
#   shift | at | condition | action | arguments (separated by |)
# actions:
#   hq | sender | kind | text          a corkHQ message (kind: directive notice warning order)
#   say | robot | text                 a robot says it (on camera, and in the Facility Log)
#   learn | key                        the supervisor learns / a flag is set
#   fault | device                     a plant fault (pipe_1, relay, gate, door_dock, cam_3, uplink...)
#   seize | robot                      a unit seizes up (needs a manual reboot)
#   wear | robot | amount              add wear to a unit
#   directive | kind | target | minutes | text    a corporate demand with a deadline (see directives.gd)
#   audit | strictness                 an audit right now (strictness adds to the odds)
#   job | title | skill | station | work seconds
#   perform | robot | clip             the robot performs a clip, if it's been recorded (see docs/STORY.md)
#   stability | robot | amount         nudge a robot's software stability
#   standing | amount | why            suspicion | amount | why
#   end | ending id                    end the game now
